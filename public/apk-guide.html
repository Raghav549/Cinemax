CineMax APK

Build Guide

Method 1 — PWABuilder (Easiest)

STEP 01

Visit pwabuilder.com and paste your deployed CineMax URL.

STEP 02

Click Start — PWABuilder will analyse your manifest and service worker automatically.

STEP 03

Click Package for Stores → choose Android → click Generate Package.

STEP 04

Download the .apk or .aab file. Install directly on Android via USB or upload to Play Store.

Method 2 — Bubblewrap CLI

STEP 01

Install Bubblewrap:

npm install -g @bubblewrap/cli
STEP 02

Initialize the project (replace URL with your deployed URL):

bubblewrap init --manifest https://your-cinemax-url.com/manifest.json
STEP 03

Build the APK:

bubblewrap build
STEP 04

Find your APK at ./app-release-signed.apk — install on Android!

Method 3 — Android Studio (Advanced)

STEP 01

Open Android Studio → New Project → choose Trusted Web Activity template.

STEP 02

Set the Launch URL to your deployed CineMax URL.

STEP 03

Add your assetlinks.json to /public/.well-known/ for Digital Asset Links verification.

STEP 04

Build → Generate Signed Bundle/APK → export and distribute.

💡 Tip: For the APK to work fully as a native experience (no browser bar), deploy CineMax to a public HTTPS domain first (Vercel, Railway, etc.), then use PWABuilder with that URL. The manifest.json and service worker are already configured correctly in this build.

REQUIRED FOR TWA
